Key Features

✓Neural Concept Engine — generates 3 distinct creative angles (Humorous, Direct Response, Minimalist Premium) from a single brand input.
✓Dynamic Reflow Engine — instantly reformats every poster across 1:1, 9:16, and 16:9 without redesigning.
✓4 Trending Visual Styles — Cyberpunk Neon, Glassmorphism Premium, Gradient Mesh Editorial, and Minimal Luxury shader backdrops.
✓Contrast & Accessibility Scorer — real WCAG-based contrast math, not a placeholder number.
✓Animated GIF Export — renders a genuine multi-frame animated GIF (particle drift + CTA pulse) you can download and post directly.
✓Batch Export (ZIP) — one click packs all 3 variants × 3 ratios (9 PNGs) into a downloadable .zip.
✓Campaign History — every generation is saved in your browser (🕘 icon, top right); reload any past campaign instantly, even after closing the tab.
✓Agentic Pipeline View — watch a 5-role agent chain (Scraper → Strategist → Copywriter → Designer → QA) work through each generation, mirroring how the real backend orchestration is architected.
✓High-Res PNG Export — one click, full resolution, ready for print or social.
✓Creative JSON Schema View — inspect and copy the exact structured spec behind every variant.
✓Docker-Ready Backend — the full production stack (Next.js + FastAPI + Postgres + Redis + vector DB + CNN service) ships with Dockerfiles & docker-compose.yml in this package — see ARCHITECTURE.md.
✓Real RAG (Retrieval-Augmented Generation) — a local knowledge base of proven ad-copy formulas is actually searched (lexical/keyword scoring) and the top match grounds your Direct-Response headline. Genuine retrieval, no network call.
✓Real CNN Logo Analysis — upload a logo and a genuine MobileNet convolutional neural network (TensorFlow.js, runs in your browser) classifies it, plus a real pixel-histogram pass extracts its dominant colors — apply them to your palette in one tap.
✓Autonomous QA Agent — genuinely checks each campaign's average accessibility score and, if it's below threshold, independently retries with a higher-contrast palette — a real decide-and-retry loop, not just an animation.

FAQ

·Is the image generation real AI (FLUX/Midjourney)? Not that part — poster backgrounds use procedural shader rendering so it works offline with zero API cost. But the CNN logo analysis and RAG copy retrieval ARE real — genuine MobileNet inference and genuine local knowledge-base search, both running live in your browser.
·Where is my history stored? Locally in this browser (localStorage). Clearing browser data will clear it — nothing is sent to a server.
·Can I self-host the full backend? Yes — see the Dockerfile + docker-compose.yml included in the package for a one-command deploy of the production stack.
